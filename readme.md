CONDITIONS:
create a .env file with following contents:

- SECRET_KEY (use uuid v4)
- GENERATIVETOKEN_KEY (use uuid v4)
- INTERMEDIATE_KEY (use uuid v4)
- APP_PORT (recommend 8100 but any is fine, but it must be a port number thats not being used!!!!!)

IMPORTANT RUN COMMANDS

- npm run buildapp (runs the esbuild js and runs app on APP_PORT from your .env file)
